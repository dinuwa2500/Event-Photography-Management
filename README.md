
# Event Photography Management System

A modern, responsive website for event photography services, allowing users to browse services, view pricing, and book photography sessions for various events.

## Features

- **Responsive Design**: Works on desktop and mobile devices
- **User Authentication**: Login and signup functionality
- **Service Showcase**: Display of photography services and portfolio
- **Pricing Information**: Transparent pricing for different photography packages
- **Contact Form**: Easy way for potential clients to get in touch
- **Social Media Integration**: Links to various social media platforms
- **Terms & Privacy**: Legal pages for terms of service and privacy policy

## Pages

- **Home**: Landing page with featured work
- **About Us**: Information about the photography service
- **Pricing**: Detailed pricing for different photography packages
- **Contact Us**: Contact form and information
- **Login/Signup**: User authentication pages
- **Reviews**: Testimonials from previous clients
- **Payment**: Secure payment processing
- **Terms & Privacy**: Legal information

## Technologies Used

- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript (ES6+)
  - Web Components for reusable UI elements

## Getting Started

1. Clone the repository:
   `ash
   git clone <repository-url>
   `

2. Open the project folder:
   `ash
   cd Event-Photography-Management
   `

3. Open index.html in your preferred web browser to view the website.

## Usage

1. Browse through the website to view services and pricing
2. Create an account or log in to book photography services
3. Contact the team for custom inquiries
4. Make payments for booked services
